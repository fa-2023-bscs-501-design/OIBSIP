# Level 1 — Task 1: Landing Page

## 1. Project Overview

This project is a visually polished static landing page developed as part of the Oasis Infobyte Web Development and Designing Internship.

The objective of this task was to build a responsive landing page using HTML5 and CSS3 while applying fundamental web development concepts such as navigation, hero sections, content sections, responsive layouts, spacing, typography, and consistent visual styling.

## 2. Technologies Used

* HTML5
* CSS3
* Flexbox
* CSS Media Queries

No JavaScript was required for this task.

## 3. Main Features

### Navigation Bar

The landing page contains a fixed/sticky navigation bar with multiple navigation links. The navigation allows users to move between different sections of the page.

### Hero Section

The hero section contains:

* A main headline
* Supporting text
* A call-to-action button

The call-to-action provides a clear path for the user to explore the page.

### Features Section

A dedicated features section presents the main features of the selected product/service in a structured layout.

### About Section

The About section provides additional information about the product/service and supports the overall purpose of the landing page.

### Footer

The page includes a footer containing placeholder contact and social links as required by the task.

## 4. Design and Styling

A consistent colour palette has been applied throughout the landing page to maintain visual consistency.

CSS was used to control:

* Typography
* Colours
* Spacing
* Padding and margins
* Section layouts
* Buttons
* Cards
* Navigation
* Responsive behaviour

Different font sizes were used for headings and body text to maintain a clear visual hierarchy.

## 5. Responsive Design

The landing page was designed to work on both desktop and mobile screen widths.

CSS media queries and Flexbox were used to adjust the layout for smaller screens. Content sections stack appropriately on mobile devices so that elements do not overlap or become difficult to read.

## 6. Layout and Spacing

The `box-sizing: border-box` approach was used to make sizing more predictable.

Intentional padding, margins, gaps, and section spacing were applied to prevent element overlap and maintain a clean layout.

## 7. Testing

The landing page was tested visually at different screen sizes to ensure:

* Navigation remains usable
* Hero content remains readable
* Sections do not overlap
* Buttons remain accessible
* Content fits properly on mobile screens
* The overall layout remains visually consistent

A final screenshot is included in the `screenshots` folder.
