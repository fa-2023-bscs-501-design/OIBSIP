# Level 1 — Task 2: Personal Portfolio

## 1. Project Overview

This project is a personal portfolio website developed as part of the Oasis Infobyte Web Development and Designing Internship.

The objective was to create a responsive personal portfolio that presents my profile, background, technical skills, projects, and contact information in a clear and professional layout.

## 2. Technologies Used

* HTML5
* CSS3
* Flexbox
* CSS Media Queries

JavaScript was not required for the core functionality of this project.

## 3. Main Features

### Profile / Hero Section

The portfolio includes a hero section containing:

* My name — Meerab Asif
* Role title — Frontend Developer
* Professional profile image
* Short introduction
* Call-to-action button

The profile image is stored locally as `profile.png`.

### About Me Section

The About section provides a short introduction describing my background, interests, and focus in web development.

### Skills Section

A dedicated Skills section presents my technical skills in a structured visual layout.

The section is designed using CSS Grid to keep the skill items organized and readable.

### Projects Section

The Projects section contains project cards with:

* Project title
* Project description
* GitHub repository link area

The cards use a consistent layout and equal sizing to maintain visual balance.

### Contact Section

A Contact section is included to provide a clear area for contact information and professional links.

### Navigation

The navigation bar contains links to:

* Home
* About
* Skills
* Projects
* Contact

The links use section IDs to navigate between different parts of the portfolio.

## 4. Smooth Scrolling

CSS smooth scrolling is enabled so navigation between sections provides a smoother browsing experience.

## 5. Profile Image

The project includes a locally stored profile image:

```text
profile.png
```

This image is displayed in the hero section using an HTML `<img>` element.

## 6. Design and Branding

The portfolio uses a consistent colour scheme and typography throughout the website.

CSS styling was used for:

* Navigation
* Hero section
* Buttons
* Skill cards
* Project cards
* Contact section
* Footer
* Spacing and alignment
* Responsive layouts

A consistent visual hierarchy was maintained by using different font sizes for headings, subheadings, and body text.

## 7. Responsive Design

The portfolio was designed to remain usable on both desktop and mobile screen sizes.

CSS media queries are used to adjust:

* Navigation layout
* Hero section
* Profile image placement
* Skills grid
* Project cards

On smaller screens, the content stacks vertically and remains readable without overlapping.

## 8. Testing

The portfolio was tested at desktop and mobile screen widths.

The following areas were checked:

* Navigation links
* Hero section
* Profile image
* About section
* Skills section
* Project cards
* Contact section
* Footer
* Mobile responsiveness
* Project card alignment
* Spacing and element positioning

A final screenshot is stored in the `screenshots` folder.
